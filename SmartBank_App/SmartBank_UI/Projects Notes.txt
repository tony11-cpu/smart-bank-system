Production Service Notes:
1) Service Name: HandlingSchedualedTransfaresService
2) StartType: Automatic (Delayed)
3) Current expected runtime account: LocalSystem
4) DB Connection uses Trusted_Connection=True
5) SQL permissions are required for service account in each environment.

SQL Permission Setup Needed In Deployment:
USE [master]
CREATE LOGIN [NT AUTHORITY\SYSTEM] FROM WINDOWS

USE [SmartBankDB]
CREATE USER [NT AUTHORITY\SYSTEM] FOR LOGIN [NT AUTHORITY\SYSTEM]
ALTER ROLE [db_owner] ADD MEMBER [NT AUTHORITY\SYSTEM]

Service Health Check Steps:
1) Confirm service is running:
   Get-Service HandlingSchedualedTransfaresService
2) Confirm account:
   sc.exe qc HandlingSchedualedTransfaresService
3) Confirm log updates every 5 minutes with processed count.

Important Operational Behavior:
1) Scheduled transaction insert starts with BalanceBefore = BalanceAfter (Pending).
2) After service processing, scheduled row BalanceAfter is updated and immediate transfer row is added.
3) If log shows login failed, it is environment permission issue, not timer issue.
